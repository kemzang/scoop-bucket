# scoop-bucket

Scoop bucket for [Arclio](https://arclio.net) — a free, open-source desktop app that downloads videos, audio, playlists, and subtitles from YouTube and 2000+ other sites.

## Install

```powershell
scoop bucket add arclio https://github.com/kemzang/scoop-bucket
scoop install arclio/arclio
```

## Update

`bucket/arclio.json` is bumped automatically by [Arclio's release pipeline](https://github.com/kemzang/Arclio/blob/main/.github/workflows/release.yml) on every stable release. No manual edits needed.
